# 프로젝트 관리

[전체 목차](../README.md) · [데이터 모델](../02-data-model.md) · [API](../03-api.md)

## 목적과 URL

`/projects`는 만다라트 목표(`Goal`)와 일일·수집함 할 일(`Todo`) 사이의 완수 단위인 **프로젝트**를 관리합니다. `?project=<id>` 쿼리로 진입하면 전체 상태 필터로 전환하고 해당 프로젝트 카드를 자동으로 펼쳐 보여줍니다.

## 화면 구성과 동작

1. **상단 요약 카드**: 진행 중 프로젝트 수, **다음 행동 필요** 프로젝트 수(`status === 'active'`이면서 대기·연기 상태 할 일이 0개), 7일 이내 마감 또는 마감 지연 프로젝트 수를 집계합니다.
2. **상태·목표 필터**: `진행 중`(기본) · `예정` · `보류` · `완료` · `전체` 탭과 상위 만다라트 목표 드롭다운으로 목록을 좁힙니다.
3. **프로젝트 생성·편집 대화상자**: 제목(필수), 상태, 마감일(`YYYY-MM-DD`), 상위 목표, 카테고리, 완료 기준 한 줄(`outcome`), 프로젝트 메모(`note`)를 저장합니다.
4. **프로젝트 카드와 상세 워크스페이스**:
   - 카드 상단에서 상태를 즉시 변경하거나 편집·삭제할 수 있습니다.
   - 연결된 할 일의 완료율(취소 항목 제외)과 연결된 할 일에 기록된 **실제(`actual`) 시간블록 합계**를 표시합니다.
   - **오늘 할 일 추가** 또는 **수집함 할 일 추가** 버튼으로 공통 `TodoCreateInput`을 열어 다음 행동을 바로 등록합니다. 프로젝트의 상위 목표와 카테고리가 새 할 일에 기본 연결됩니다.
   - 상세 영역에서 연결된 할 일의 상태 변경, 제목 편집, 수집함·과거 할 일의 **오늘로 배정**, 상세 설정, 메모, 프로젝트 메모 편집을 수행합니다.

## 다른 화면과의 연결

- 일일·주간·월간·수집함 할 일의 **상세 설정**(`TodoDetailsButton`)에서 `연결 프로젝트`를 지정하거나 해제할 수 있습니다. 프로젝트를 선택할 때 할 일의 목표가 비어 있거나 이전 프로젝트의 목표와 같으면 새 프로젝트의 상위 목표를 자동으로 채우며, 사용자가 다른 목표나 `목표 없음`으로 개별 변경할 수 있습니다.
- 할 일 목록과 월간 날짜 서랍에는 `📁 프로젝트명` 링크가 표시되며 클릭 시 `/projects?project=<id>`로 이동합니다.
- 프로젝트를 삭제하면 즉시 트랜잭션으로 연결된 할 일의 `projectId`만 `null`로 해제하며, 할 일 자체와 상위 목표 연결은 보존합니다.
- 전체 검색(`/search`)의 `프로젝트` 범위에서 제목·완료 기준·메모를 검색할 수 있습니다.
