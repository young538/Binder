# 월간 계획

[전체 목차](../README.md) · [일일](06-daily.md) · [주간](05-weekly.md)

## 목적과 구성

`/monthly/[yyyymm]`, 예를 들어 `/monthly/2026-09`에서 월 단위 방향과 날짜별 실행을 봅니다.

위에서부터 이전·다음 월 이동, 이번 달 한 문장, 목표 진행 요약, 습관 달력, 날짜별 TODO 달력, 이번 달 TODO 순서입니다.

## 이번 달 한 문장과 목표 요약

한 문장은 `focus_notes(scope=month, scopeKey=month:2026-09)`에 1초 지연 저장합니다.

목표 진행 요약은 제목이 있는 코어 최대 8개를 보여주고, 코어가 없으면 서브 최대 6개를 보여줍니다. `/api/progress?goalIds=...` 결과로 숫자 목표·습관·TODO와 투자 시간을 표시합니다.

`GoalSummaryStrip`은 선택 월의 첫날을 서버에 전달해 해당 기간 진행률을 계산합니다. 자손 목표까지 합산하지 않고 지정 목표에 직접 연결된 항목을 계산합니다.

## 습관 달력

세로는 습관, 가로는 선택 월의 날짜입니다. 이름 열을 고정하고 좁은 화면에서는 가로 스크롤합니다. 오늘 날짜를 강조합니다.

매일 습관은 모든 날짜, 요일 습관은 해당 요일만 체크할 수 있습니다. 주 N회·월 N회 습관은 기간 안에서 원하는 날짜에 체크할 수 있습니다. 적용되지 않는 고정 요일 칸은 비활성화합니다.

클릭하면 `/api/habit-logs`로 `{ habitId, date }`를 보내고 습관과 로그를 재조회합니다. 일일·주간의 동일 습관 로그를 사용하므로 저장 데이터는 공유됩니다. 같은 브라우저 실행 컨텍스트의 구독 화면은 리소스 변경을 받아 갱신합니다. 다른 탭·기기의 실시간 갱신은 제공하지 않습니다.

## 날짜별 TODO 달력

월요일 시작 7열 달력입니다. 월 시작·끝 주를 채우기 위해 인접 월의 날짜도 표시하고, 전체 표시 범위의 **일일 TODO만** 조회합니다. 해당 월의 `scope=month` TODO가 날짜 칸으로 자동 분배되지는 않습니다.

한 날짜에 최대 5개를 미리 보여주며 초과분은 `+N개`로 표시합니다. 카테고리 색, 우선순위 별표, 상태별 스타일을 표시합니다. 날짜 클릭 시 오른쪽 서랍이 열립니다.

## 날짜 TODO 서랍

선택한 날짜의 목록을 조회해 다음을 제공합니다.

- TODO 추가: TodoCreateInput에서 Enter 또는 포커스 이탈로 한 번만 생성, 기본 상태 pending. 한글 조합 Enter는 저장하지 않고 실패하면 입력을 유지합니다.
- 제목 수정: 선택 후 더블클릭·Enter·연필 버튼 등으로 편집.
- 상태 선택: 대기·완료·연기·위임·취소.
- 우선순위: 없음 → 1 → 2 → 3 → 없음 순환.
- 카테고리 선택·해제, 코어·서브 목표 연결·해제.
- 삭제: 확인 후 해당 TODO 삭제.

서랍을 닫으면 달력의 목록을 다시 읽습니다. 일일 화면과 주간 화면의 같은 날짜 TODO도 이 레코드를 사용합니다.

우선순위는 없음 → 1 → 2 → 3 → 없음으로 순환합니다. 우선순위·카테고리·목표의 명시적 해제는 `null`을 사용합니다.

## 이번 달 TODO

`TodoListSection(scope=month, scopeKey=2026-09)`를 재사용합니다. 추가·제목 수정·상태 변경·카테고리 선택·삭제가 가능합니다. 기존 상위 목표 연결이 있으면 제목을 표시하지만 이 공통 목록에서 목표를 선택하는 UI는 없습니다.

달력·날짜 서랍·습관·목표 요약의 조회는 `useAsyncResource`를 사용합니다. 기간·날짜가 바뀌면 이전 조회 결과가 새 화면을 덮어쓰지 않습니다.

## TODO 이월과 삭제 취소

날짜별 TODO 목록의 **미완료 N개 다음 날로**를 누르면 pending·postponed 항목이 다음 날짜로 이동합니다. 같은 ID를 유지하며 시간 기록은 원래 날짜에 남습니다. 월/주 단위 TODO에는 이월 버튼을 표시하지 않습니다. 삭제 후 하단 알림의 **실행 취소**로 30초 이내 같은 TODO를 복원할 수 있습니다. 알림은 현재 브라우저에서만 표시되고 새로고침 뒤에는 유지되지 않습니다.
