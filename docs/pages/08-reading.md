# 독서 리스트

[전체 목차](../README.md) · [일일 독서](06-daily.md)

## 목적과 화면

`/reading`에서 연도별 도서 목록을 관리합니다. 초기 연도는 브라우저의 현재 연도이며 전년·다음 연도 버튼으로 변경합니다. 선택 연도는 URL에 저장하지 않으므로 새로 진입하면 현재 연도로 시작합니다.

목록 위에는 등록 도서 수와 완독 수, 책 추가 버튼이 있습니다. 완독 수는 `finishedAt` 값이 있는 행의 수이며 별도 완료 상태는 없습니다.

## 입력 필드

| 화면 열 | 데이터 | 설명 |
|---|---|---|
| No. | `order` | 생성 시 목록 길이 + 1 |
| 카테고리 | `category` | 책 전용 자유 텍스트; 공통 카테고리 ID와 다름 |
| 도서 제목 | `title` | 제목 |
| 1 Thing | `oneThing` | 책의 핵심 한 문장; 목표 보드 연결이 아님 |
| 3 Keywords | `keywords` | 하나의 문자열; 3개 제한·배열 저장 없음 |
| 완독일 | `finishedAt` | 날짜, 비우면 null |
| 서평 | `reviewUrl` | URL 입력과 새 탭 열기 |

책 추가는 제목이 빈 행을 먼저 POST한 후 해당 제목 입력에 포커스를 줍니다. 각 입력은 포커스 이탈 시 PATCH하며 삭제는 확인 후 DELETE합니다. 선택 필드의 빈 값은 null로 저장합니다.

표 최소 폭은 900px입니다. 모바일도 동일 표를 가로 스크롤하며 별도 카드 화면이 아닙니다. `startedAt`은 타입·DB에는 있지만 현재 표에 시작일 입력은 없습니다.

## 일일 독서와의 관계

일일 페이지에서 현재 연도의 이 목록을 책 선택지로 사용합니다. 선택 당시 책 제목과 ID를 날짜별 독서 JSON에 저장합니다. 일일 기록 쪽수 합산으로 완독일을 갱신하거나 습관을 자동 체크하지 않습니다.

책을 삭제해도 날짜별 독서 JSON을 찾아 정리하지 않습니다. 기록에 저장된 제목이 남을 수 있으며, 이미 열린 일일 화면의 책 선택지는 목록 변경 후 자동 재조회되지 않습니다.

## 구현 파일

| 파일 | 역할 |
|---|---|
| [ReadingPage](../../components/reading/ReadingPage.tsx) | 연도별 AsyncResource 조회, 표, 완독 수, 인라인 편집 |
| [클라이언트 books repository](../../lib/repo/books.ts) | 연도 조회와 변경 API |
| [서버 books repository](../../lib/server/repos/books.ts) | 사용자·연도별 조회, CRUD |
| [DailyReading](../../components/daily/DailyReading.tsx) | 목록을 사용하는 날짜별 기록 |

외부 도서 검색, ISBN 조회, 표지 수집, 독서 시간 자동 추적, 책별 누적 쪽수 통계는 구현되어 있지 않습니다.

전체 검색에서 독서 결과를 누르면 `/reading?year=YYYY`로 이동해 해당 연도를 초기 선택합니다. 이후 화면의 연도 이동은 내부 상태로 처리합니다.
