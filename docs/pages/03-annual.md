# 연간 계획

[전체 목차](../README.md) · [일일 루틴](06-daily.md) · [데이터 모델](../02-data-model.md)

## 목적과 화면

`/annual/[year]`는 한 해의 목표를 월별 숫자로 관리합니다. 전년·다음 연도 이동, 올해 한 문장, 연간 목표 표, 일일 루틴 관리 링크로 구성됩니다.

최초 로딩 시 `ensureSeven(year)`를 호출해 해당 연도 목표가 7개 미만이면 빈 행을 보충합니다. 최소 표시 행을 DB에 실제로 생성하는 방식입니다. 7개를 넘어 추가할 수 있으며, 삭제 후 다시 페이지에 들어오면 부족한 행이 다시 생깁니다.

## 목표 한 행의 필드

| 항목 | 용도와 저장 |
|---|---|
| 이루고 싶은 일 | `title`, 포커스 이탈 저장 |
| 목표 | `target`, 연간 총 목표 |
| 단위 | `metric`, 권·회·kg 등의 자유 텍스트 |
| 1~12월 계획 | `monthlyTargets[0..11]`, 빈칸은 null |
| 1~12월 실적 | `monthlyActuals[0..11]`, 빈칸은 null |
| 상위 목표 | `parentGoalId`, One-Thing·코어·서브 선택 또는 해제 |
| 달성 기한 | `deadline`, 데스크톱 상세 행·모바일 카드의 텍스트 입력 |
| 실천 내용 | `action`, 데스크톱 상세 행·모바일 카드 |
| 달성률 | 월 실적 합 / 연 목표 × 100, 반올림 |

연 목표가 없거나 0 이하이면 달성률은 `-`로 표시합니다. 표의 달성률은 100%를 초과할 수 있습니다.

## 수동 입력과 자동 계산

월 계획을 수정하면 12개월 계획을 복사해 해당 위치를 수정하고 PATCH합니다. 서버가 월 계획 합으로 연 목표를 갱신하며 모두 지우면 연 목표도 0이 됩니다.

연결 습관이 있는 행은 연 목표와 월 계획이 읽기 전용이며 잠금 표시가 나옵니다. 서버가 연결 습관의 반복 일정으로 월 계획과 연 목표를 계산합니다. 여러 습관이 연결되면 합산합니다. 월 실적은 실제 체크 로그에서 계산하며 표에서 수동 편집한 차이는 별도 보정값으로 유지합니다.

예: 매일 습관을 2026년 목표에 연결하면 월 계획은 각 월의 날짜 수이고 연 목표는 365입니다. 9월에 체크하면 9월 실적이 1 증가합니다. 시간블록이나 TODO 완료가 이 숫자를 자동 증가시키지는 않습니다.

## 화면 크기에 따른 차이

`md` 이상은 최소 폭 1220px의 가로 스크롤 표입니다. 상반기·하반기 색을 나누고 월별 셀 위에 계획, 아래에 실적을 표시합니다. 펼치기 버튼으로 상위 목표·기한·실천 내용을 편집합니다.

`md` 미만은 목표별 카드로 바뀌며 제목·상위 목표·기한·실천 내용·연 목표·단위·월 계획·실적을 편집합니다. 월별 계획·실적은 카드 안에 4열로 배치하고, 연결 습관과 달성률도 카드에 표시합니다.

## 데이터와 저장

올해 한 문장 키는 `scope=year`, `scopeKey=year:2026`과 같은 접두사 형식입니다. 목표 표는 `annual_goals.year=2026`을 조회합니다. 이 화면은 `scope=year` TODO 목록을 렌더링하지 않습니다.

목표나 습관이 바뀌면 `onDirty()` 구독으로 목표와 연결 습관을 다시 읽습니다. 연결 상태는 습관의 `annualGoalId`를 기준으로 판단합니다.
