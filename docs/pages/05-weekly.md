# 주간 계획과 시간표

[전체 목차](../README.md) · [회고](07-retrospective.md) · [API](../03-api.md)

## 목적과 구성

`/week/[isoweek]`, 예를 들어 `/week/2026-W37`에서 한 주의 할 일과 시간을 기록합니다. 기본 `/` 진입은 오늘의 일일 화면이며, 주간 화면은 메뉴로 이동합니다. ISO 주차 기준 월요일~일요일 7일을 사용합니다.

`md` 이상에서는 `WeekGrid`, 그 미만에서는 `DayListView`를 표시합니다. 주간 습관 체크는 이번 주 TODO 위의 공통 정리 영역에서 한 번만 렌더링합니다. 데스크톱 시간표의 습관 이름 목록과 모바일의 별도 습관 이름 표시는 이 체크 표로 통합했습니다(2026-09-09).

## 데스크톱 시간표

주 이동, 이번 주 한 문장, 목표 진행 요약, 이번 주 TODO, 날짜별 TODO, 시간표 순서입니다. 이번 주 TODO 바로 위에 주간 습관 체크와 실제 시간 통계를 배치합니다. 목표 요약과 시간 통계는 접기 버튼 없이 표시합니다. 한 문장은 `scope=week`, `scopeKey=week:2026-W37`, 주 TODO는 `scope=week`, `scopeKey=2026-W37`을 사용합니다.

좌표·범위 계산은 `TimeGridGeometry`, 이동·복사 저장 정책은 `TimeBlockCommands`에 분리돼 있으며 일일 화면도 같은 객체를 사용합니다. 그리드는 7일 × [계획, 실제] = 14개 시간 열입니다. 설정의 `dayStartHour`, `dayEndHour`, `gridMinutes`로 행 수를 정하고 한 행 높이는 32px입니다. 기본 06:00~23:00, 30분이면 34행입니다.

블록은 `startMin`, `endMin`으로 세로 위치와 높이를 계산합니다. 계획은 점선과 옅은 채움, 실제는 실선과 진한 채움으로 구분합니다. 색은 연결 카테고리를 사용합니다.

## 선택·생성·편집

| 조작 | 동작 |
|---|---|
| 빈 칸 1회 클릭 | 칸 선택과 강조; 모달은 열지 않음 |
| 빈 칸 마우스 더블클릭 | 해당 한 칸 범위로 블록 편집기 열기 |
| 선택 칸 Enter/F2 또는 추가 버튼 | 선택 위치의 편집기 열기 |
| 빈 칸에서 마우스로 여러 행 드래그 | 선택 범위로 편집기 열기 |
| 기존 블록 1회 클릭 | 블록 선택 |
| 기존 블록 마우스 더블클릭, 선택 후 편집 | 기존 블록 편집기 |
| 모달 Enter / Escape | 저장 / 닫기; 한글 조합 중 Enter 제외 |

빈 칸 범위 드래그는 Pointer Events와 좌표 아래 요소의 행 추적으로 처리하며, 기존 블록 이동·복사는 포인터 캡처를 사용합니다. 시작 날짜와 종류 열을 고정하고 시작·현재 행의 최소~최대 범위를 사용합니다. 마지막 행도 범위에 포함합니다. 포인터 취소 시 드래그를 해제합니다.

공통 시간표를 터치로 조작할 때는 빈 칸·기록 위에서 스크롤하고, 탭으로 선택한 뒤 버튼으로 추가·편집합니다. 터치 드래그로 생성·이동하거나 두 번 탭해 편집기를 열지 않습니다.

## 기존 블록 이동과 복사

기존 블록을 마우스로 약 4px 이상 드래그하면 이동으로 판단합니다. 포인터 아래의 시간 열에서 날짜·계획/실제·시작 행을 찾고, 기존 길이를 유지해 저장합니다. 드래그 종료 후 잔여 클릭이 편집기를 열지 않도록 막습니다.

Ctrl·Alt·Meta 중 하나를 누른 드래그는 복사입니다. 다른 날짜로 **복사**할 때 TODO 연결을 생략하지만 목표·카테고리·내용·길이는 유지합니다. 같은 날짜 복사는 TODO 연결도 유지합니다. **이동**은 날짜와 시간, 종류만 수정하므로 다른 날짜로 옮겨도 기존 TODO 연결이 남습니다.

편집기의 다음 날 복사 버튼은 다음 날짜와 같은 시간·내용·목표·카테고리로 새 편집기를 엽니다. 최종 저장 전에는 복제 행이 만들어지지 않습니다.

## 블록 편집기

내용, 계획/실제, 시작·종료 시각, 카테고리, 목표, 해당 날짜의 TODO를 편집합니다. 기본 카테고리는 공통 카테고리 목록의 첫 항목입니다. 시간은 설정의 그리드 단위로 스냅하고 종료가 시작보다 늦은지 확인합니다.

새 블록은 POST, 기존 블록은 PATCH합니다. 삭제는 확인 후 DELETE합니다. 목표·TODO 선택 해제는 null을 보냅니다. 블록 생성·삭제·실제 전환이 TODO 상태를 자동 완료로 바꾸지는 않습니다.

일별·주별 TODO 추가는 공통 TodoCreateInput을 사용합니다. 한글 조합 확정 Enter는 제외하고, Enter·포커스 이탈·연타가 겹쳐도 한 입력당 한 생성 요청만 실행합니다. 실패하면 초안을 유지합니다.

날짜별 TODO의 시계 버튼은 제목과 TODO ID를 미리 채운 계획 블록 편집기를 엽니다. 시작은 설정의 시작 시각, 길이는 한 그리드 칸입니다. TODO의 카테고리·목표가 모두 자동 상속되는 구현은 아니므로 편집기에서 확인합니다.

## 모바일 목록

해당 주에 오늘이 있으면 오늘, 없으면 월요일로 시작합니다. 이전·다음 날 버튼은 현재 주 안에서만 이동하며 주 경계를 넘지 않습니다. 접을 수 있는 TODO, 시간순 블록 카드, 블록 추가, 일일 회고를 제공합니다. 습관은 할 일 위의 공통 체크 표에서 확인합니다.

블록 한 번 누르기는 선택, 더블클릭·수동 더블탭·편집 버튼은 편집입니다. 데스크톱의 드래그 격자를 모바일에 그대로 제공하지 않습니다.

## 습관과 통계

주간 습관 체크는 해당 주 전체 로그를 읽고 7일 표를 기본 표시합니다. 요일과 날짜를 한 줄로 묶고, 습관 이름과 반복 주기를 같은 행에 배치합니다. 모바일에서는 반복 주기를 툴팁에 남겨 이름과 7일 체크가 화면 폭 안에 들어오도록 합니다. 각 행 높이는 28px, 체크 표시 16px이며 셀 전체를 눌러 체크합니다. 저장 중 중복 클릭을 막고 실패 메시지를 표시합니다.

`GoalCoverageBar`는 전달된 주간 블록 중 actual만 골라 목표별·카테고리별 시간을 합산합니다. 미지정·삭제된 연결은 대체 문구로 표시합니다. `GoalSummaryStrip`은 선택 주 월요일을 기준 날짜로 전달하며 실제 시간만 집계합니다. 월별 지표는 해당 월요일이 속한 월의 값입니다.

## 조회와 반응형 실행

`WeeklyDataProvider`가 선택 주 시간블록과 일별 TODO를 각각 한 범위 요청으로 읽고 하위 화면에 공유합니다. `WeeklyViews`는 브라우저 media query로 PC/모바일 중 하나만 마운트합니다. 화면 너비가 바뀌어도 provider의 데이터는 유지합니다. 수정 이벤트는 todos/timeBlocks를 구분해 해당 데이터만 새로 읽고 늦게 도착한 이전 응답은 무시합니다. 조회 실패 시 다시 시도 버튼이 나타납니다.

2026-09-09 배치 보완: `WeeklyReview`는 PC에서는 이번 주 TODO 위, 모바일에서는 오늘 할 일 위에서 통합 습관 표와 목표별·카테고리별 실제 시간 통계를 표시합니다. 기존 접힘 설정과 무관하게 통계를 항상 렌더링합니다.

하단 시각 구성: 시간표와 같은 폭·배경을 사용하는 연결 영역으로 표시합니다. 습관 카드의 바깥 그림자와 테두리는 생략하고, 통계는 얇은 구분선과 동일한 좌우 여백을 사용합니다. 모바일 하단은 공통 메뉴 여백에 추가 버튼 공간만 더해 빈 공간의 중복을 줄입니다.

배치 조정: `WeeklyReview`는 활성 뷰 안에서만 렌더링합니다. PC는 목표 진행 요약 → 습관·실제 통계 → 이번 주 TODO 순서이며, 모바일은 날짜 이동 → 습관·실제 통계 → 오늘 할 일 순서입니다. 추가 버튼용 하단 여백은 모바일 뷰 맨 끝으로 옮겼습니다.

## TODO 이월과 삭제 취소

날짜별 TODO 목록의 **미완료 N개 다음 날로**를 누르면 pending·postponed 항목이 다음 날짜로 이동합니다. 같은 ID를 유지하며 시간 기록은 원래 날짜에 남습니다. 월/주 단위 TODO에는 이월 버튼을 표시하지 않습니다. 삭제 후 하단 알림의 **실행 취소**로 30초 이내 같은 TODO를 복원할 수 있습니다. 알림은 현재 브라우저에서만 표시되고 새로고침 뒤에는 유지되지 않습니다.
