# 로그인과 공통 이동

[전체 목차](../README.md) · [인증/API](../03-api.md)

## 목적과 URL

`/login`에서 계정으로 로그인합니다. `/`와 `/daily`는 오늘의 `/daily/YYYY-MM-DD`로 이동합니다. 공개 회원가입·관리자 페이지·비밀번호 변경 UI는 없습니다. 계정 관리는 서버 CLI로 수행합니다.

## 화면과 동작

아이디 입력의 초기값은 `admin`입니다. 비밀번호가 비었거나 요청 중이면 로그인 버튼을 비활성화합니다. 제출 중에는 로그인 중 표시가 나오며 잘못된 인증 정보와 네트워크 실패는 폼 안에 표시합니다.

로그인 성공 시 `next` 쿼리 경로 또는 `/`로 `router.replace()`한 뒤 `router.refresh()`합니다. `next`는 `/`로 시작하고 `//`로 시작하지 않는지 검사합니다. 모든 비정상 URL을 포괄적으로 정규화하는 구현은 아닙니다.

## 인증 처리

1. `POST /api/auth/login`에 `{ username, password }`를 보냅니다.
2. `verifyCredentials()`가 DB의 사용자와 argon2 비밀번호 해시를 확인합니다.
3. 성공하면 `loggedIn`, `userId`, `username`을 iron-session에 저장합니다.
4. `binder_session` 쿠키로 이후 요청을 인증합니다. 쿠키는 httpOnly, sameSite=lax, 경로 `/`, 30일 maxAge이며 production에서 secure입니다.
5. `proxy.ts`가 먼저 쿠키의 `loggedIn`을 확인합니다. 도메인 API는 `requireSession()`으로 사용자 ID와 이름까지 확인합니다.

인증되지 않은 일반 페이지 요청은 `/login?next=...`로 이동하고 API는 401을 반환합니다. `http.ts`도 401을 받으면 현재 경로·검색값을 넣어 로그인으로 이동합니다. 로그인과 로그인 API, matcher에서 제외한 이미지 등의 정적 경로는 예외입니다.

## 메뉴와 반응형

| 화면 크기 | 메뉴 |
|---|---|
| `lg` 이상 | 상단 One-Thing·일일·연간·월간·주간·회고·독서, 전체 검색·수집함, 계정 이름, 설정, 로그아웃 |
| `lg` 미만 | 하단 One-Thing·일일·연간·월간·주간·더보기 |
| 모바일 더보기 | 수집함·목표 실행 점검·전체 검색·회고·독서·설정 시트 |

활성 메뉴는 현재 pathname의 접두사로 판단합니다. 일일 메뉴는 클릭 시 브라우저의 현재 날짜를 다시 계산합니다. `/`와 `/daily` 진입도 브라우저의 시간대를 기준으로 오늘을 선택하므로 서버 시간대와 달라도 날짜가 맞습니다. 주간·회고 메뉴는 렌더링 시점의 현재 ISO 주차를 사용합니다. 날짜가 지정된 일일 URL은 해당 날짜를 그대로 표시합니다.

로그아웃은 상단 또는 설정의 계정 카드에서 수행합니다. `POST /api/auth/logout`이 세션을 파기하고 로그인 화면으로 이동합니다.

로그인 이후 StoreProvider가 공통 데이터를 초기화합니다. 실패 시 오류와 다시 시도 버튼을 표시하며, 성공한 일부 결과만으로 화면을 열지 않습니다.

## 구현 파일

로그인 화면을 제외한 모든 화면의 **빠른 메모** 또는 Alt+N으로 수집함에 입력할 수 있습니다. 모바일 주간 화면은 기존 블록 추가 버튼과 겹치지 않게 빠른 메모 버튼을 위로 배치합니다. 자세한 사용법은 [수집함 안내](../10-planning-workflow.md#7-빠른-메모와-수집함)를 확인하세요.

| 파일 | 역할 |

## 현재 범위

세션 확인 때마다 사용자가 DB에 남아 있는지 재조회하지 않습니다. 비밀번호 변경이나 계정 삭제가 이미 발급한 쿠키를 즉시 취소하는 구조도 아닙니다. 로그인 시도 제한·MFA·비밀번호 재설정 기능은 구현되어 있지 않습니다. 세부 사항은 [구현 한계](../05-verification-and-limitations.md)에 있습니다.

## 전체 검색

상단 돋보기 또는 모바일 더보기 → 전체 검색으로 `/search`를 엽니다. Ctrl/Cmd+K도 지원합니다. 검색어와 범위를 입력하고 Enter 또는 검색 버튼을 누르면 본인 데이터만 20개씩 조회합니다. 결과는 관련 날짜·연도 화면으로 연결되며 이전·다음으로 페이지를 이동합니다. 검색 범위와 한계는 [후속 개선 기록](../09-follow-up-improvements.md)을 참고하세요.
