## 사용자 조작

상단 돋보기, 모바일 더보기의 **전체 검색**, Ctrl/Cmd+K로 검색을 엽니다. 할 일·목표·연간 목표·습관·독서·포커스 노트·회고·시간표·카테고리를 검색하며 검색 결과를 누르면 해당 기간 화면으로 이동합니다. 책은 해당 연도가 선택됩니다. 검색어는 1~100자이며 `%`·`_`는 와일드카드가 아닙니다.

일일 목록, 주간 날짜 열, 월간 날짜 서랍의 **미완료 N개 다음 날로**를 누르면 미완료·연기 TODO가 이동합니다. 완료·위임·취소는 제외됩니다. 날짜는 보고 있는 날짜 기준이며 자동 일괄 이월은 하지 않습니다. 삭제 알림의 **실행 취소**는 삭제 시각부터 30초 동안 유효합니다. 알림은 새로고침·다른 브라우저에 이어지지 않습니다.

## 유지보수와 데이터 보존

- [TodoActions](../lib/server/todos/actions.ts)에 DB·사용자·시계를 주입합니다. 서버 작업은 즉시 트랜잭션이며 이월은 복제 대신 날짜 변경입니다. 삭제 후 복원은 기존 시간블록 연결을 유지합니다.
- [0006 마이그레이션](../drizzle/0006_todo_operations.sql)은 운영용 두 테이블만 추가합니다. 기존 도메인 행을 다시 작성하지 않습니다.
- [SearchRepository](../lib/server/search/repository.ts)는 모든 검색 분기에 소유자 조건을 적용합니다. 검색은 일반 SQLite 부분 문자열 조회이며 대규모 FTS 색인은 없습니다. Unicode 대소문자 변환은 SQLite 기본 lower 범위에 따릅니다.
- 검색 링크는 관련 화면입니다. 기존에 UI가 없는 year TODO·일일 포커스 노트는 검색 결과에서 내용을 확인할 수 있지만 해당 항목의 별도 편집 화면은 없습니다. 결과 자동 스크롤·강조도 제공하지 않습니다.
- 요청 기록은 지연된 재전송을 막기 위해 보존합니다. 최초 응답에는 TODO 텍스트가 포함됩니다. 만료된 삭제 스냅샷은 다음 TODO 삭제 때 정리합니다. 계정 CLI 삭제 시 두 기록도 제거합니다.
- 자동 백업은 같은 호스트에 저장하며 외부 저장소 복사는 별도입니다. 모든 자동 백업은 임시 복원과 시험 쓰기를 검증하고 성공 후에만 기간이 지난 자동 파일을 삭제합니다. 운영 DB를 덮어쓰는 복구는 자동화하지 않습니다.
